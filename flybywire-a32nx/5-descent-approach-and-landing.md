# 5 · Descent, Approach and Landing

## Descent and Approach Planning

Do this well before top of descent.

| Step | Action |
| --- | --- |
| Top of descent | calculate the required distance in **flyPad / Performance / Top of Descent** |
| [MCDU MENU / ATSU / AOC MENU / ATIS](controls.md#atsu-and-aoc) | select **SEND** |
| [MCDU MENU / ATSU / AOC MENU](controls.md#atsu-and-aoc) | select **RECEIVED MESSAGES** → **PRINT** |
| [MCDU / PERF](controls.md#performance) | fill the **APPROACH** page |

## At Top of Descent

Request descent clearance —
[ATC Communications › Centre](../vatsim/atc-communications.md#4--departure-and-centre-climb-and-cruise) — then:

| Control | Action |
| --- | --- |
| [ALT](controls.md#flight-control-unit-fcu) selector | set **cleared level** |
| [ALT](controls.md#flight-control-unit-fcu) selector | push for **managed altitude** |

## Passing 10,000 ft

| Control | Action | Condition |
| --- | --- | --- |
| [LAND L & R](controls.md#exterior-lighting) switches | set both **ON** | – |
| [SEAT BELTS](controls.md#signs) sign | set **ON** | – |
| [CSTR](controls.md#efis-control-panel) pushbutton | press | both sides [^cstr] |
| [LS](controls.md#efis-control-panel) pushbutton | press | – |
| [MCDU / RAD NAV](controls.md#radio-navigation) | verify **LS/FREQ** | – |

[^cstr]: The original note called this "CSR". The button is labelled **CSTR**
(constraints) on the EFIS control panel.

> [!NOTE]
> flyPad: perform the **APPROACH** checklist.

## Intercepting the ILS

Set up the approach once you are cleared for it and established on the intercept
trajectory:

| Control | Action | Condition |
| --- | --- | --- |
| [MCDU / PERF](controls.md#performance) | activate the **APPR** phase | automatic in NAV over the DECEL point; else about 15 NM out |
| [SPD](controls.md#flight-control-unit-fcu) knob | push for **managed speed** | – |
| [APPR](controls.md#flight-control-unit-fcu) pushbutton | press | cleared for approach, LOC deviation available |
| [AP 1](controls.md#flight-control-unit-fcu) and [AP 2](controls.md#flight-control-unit-fcu) | engage **both** | – |
| **LOC** and **G/S** on the FMA | verify **armed**, then monitor capture | – |
| Go-around altitude | set on the [ALT](controls.md#flight-control-unit-fcu) selector | – |

### At green dot speed

| Control | Action | Condition |
| --- | --- | --- |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | set **1** | about 3 NM before the final descent point |
| [TCAS mode](controls.md#atc-and-tcas) selector | set **TA/RA** | **TA** only for converging or parallel runways |

### At 2,000 ft AGL minimum

| Control | Action | Condition |
| --- | --- | --- |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | set **2** | expect deceleration toward F speed |

### When flaps are at 2

| Control | Action | Condition |
| --- | --- | --- |
| [LANDING GEAR](controls.md#autobrake-and-gear) lever | set **DOWN** | – |
| [AUTO/BRK](controls.md#autobrake-and-gear) | confirm **LO** long runway, **MED** short or contaminated | never MAX for landing |
| [SPEED BRAKE](controls.md#flaps-and-speed-brake) lever | set **ARM** | – |
| [RWY TURN OFF](controls.md#exterior-lighting) switch | set **ON** | – |
| [NOSE](controls.md#exterior-lighting) switch | set **T.O.** | – |

### When the landing gear is down

| Control | Action | Condition |
| --- | --- | --- |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | set **3** | – |
| ECAM WHEEL page | check | – |
| Landing gear lights | confirm **three greens** | – |
| [SPEED BRAKE](controls.md#flaps-and-speed-brake) lever | verify **retracted** | before selecting FLAPS FULL |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | set **FULL** | – |
| [WING ANTI ICE](controls.md#anti-ice) pushbutton | set **OFF** | leave ON only in severe icing |
| [CALLS ALL](controls.md#calls) pushbutton | press | cabin secure |

> [!NOTE]
> flyPad: perform the **LANDING** checklist.

## Landing

| Control | Action | Trigger |
| --- | --- | --- |
| [THRUST](controls.md#thrust-and-trim) levers | set **REV MAX** | immediately at main gear touchdown |
| [THRUST](controls.md#thrust-and-trim) levers | set **REV IDLE** | **70 kt** |
| [THRUST](controls.md#thrust-and-trim) levers | **stow** reversers | taxi speed |
| [AUTO/BRK](controls.md#autobrake-and-gear) | disengage — brake manually | before **20 kt** |

## Vacate the Runway

Clear the runway and stop on the taxiway before running the after-landing items.
