# 6 · After Landing and Taxi to Gate

## After Landing

Once clear of the runway and stopped on the taxiway.

| Control | Action | Condition |
| --- | --- | --- |
| [SPEED BRAKE](controls.md#flaps-and-speed-brake) lever | set **RET** | – |
| [ENG MODE](controls.md#engine) selector | set **NORM** | – |
| [FLAPS](controls.md#flaps-and-speed-brake) lever | set **0** | – |
| [TCAS mode](controls.md#atc-and-tcas) selector | set **STBY** | – |
| [PWS](controls.md#radar) switch | set **OFF** | – |
| [APU MASTER SW](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | – |
| [APU START](controls.md#auxiliary-power-unit-apu) pushbutton | set **ON** | – |
| [ENG ANTI ICE](controls.md#anti-ice) pushbutton | set **OFF** | if not required |
| [WING ANTI ICE](controls.md#anti-ice) pushbutton | set **OFF** | if not required |
| [NOSE](controls.md#exterior-lighting) switch | set **TAXI** | when leaving the runway |
| [RWY TURN OFF](controls.md#exterior-lighting) switch | set **ON** | – |
| [STROBE](controls.md#exterior-lighting) switch | set **AUTO** | **ON** again if crossing a runway |
| [LAND L & R](controls.md#exterior-lighting) switches | set both **OFF** | – |
| [WX RADAR MODE](controls.md#radar) selector | set **OFF** | avoids radiating ground crew |
| [BRK FAN](controls.md#autobrake-and-gear) pushbutton | set **ON** | if hot brakes; ideally 5 min after landing |

> [!NOTE]
> flyPad: perform the **AFTER LANDING** checklist.
